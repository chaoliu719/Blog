## 代码高亮与 shiki transformer

预期：四个代码块都有语法着色，且亮/暗主题切换时配色跟着变（`min-light` / `catppuccin-frappe` 双主题）。

普通高亮：

```ts
const site = 'liuchao.life';
export function greet(name: string): string {
  return `hello ${name}`;
}
```

行高亮（`transformerNotationHighlight`）：

```js
const a = 1;
const b = 2; // [!code highlight]
const c = 3;
```

预期：只有 `const b = 2;` 那一行有高亮背景。

单词高亮（`transformerNotationWordHighlight`）：

```js
// [!code word:astro]
const framework = 'astro';
const version = 'astro 7';
```

预期：两行里的 `astro` 这个词被单独标记（共 2 处）。

diff 标注（`transformerNotationDiff`）：

```js
const oldValue = 5; // [!code --]
const newValue = 7; // [!code ++]
```

预期：一行红底带 `-`，一行绿底带 `+`。

## 构建产物验证（可选）

除 mermaid 外，其余各项都能在生成的 HTML 里直接查。把本文 frontmatter 的
`draft` 临时改成 `false`，`pnpm build`，然后：

注意：下面的 pattern 都故意写成 `[-]`、`[_]` 这种形式，这样本节自身的字面量
不会被 grep 命中，计数才准。

```bash
f=dist/posts/2026-07-31-upgrade-smoke-test/index.html
grep -c 'class="line highlighte[d]"' "$f"          # 行高亮，预期 1
grep -c 'highlighted[-]word' "$f"                  # 单词高亮，预期 2
grep -cE 'class="line diff (add|remov[e])"' "$f"   # diff 标注，预期 2
grep -c 'heading[-]link' "$f"                      # 标题锚点，每个标题 1 个
grep -oE '<h2 id="[^"]*"' "$f"                     # 中文 slug
grep -oE '<a href="https://astro[.]build"[^>]*>' "$f"  # 外链应带 rel + target
```

验证完记得把 `draft` 改回 `true`。
